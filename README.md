# Personal Portfolio Website (`ben-kodbiz/mybio`)

Lightweight static portfolio site for Badrul (Ben), built with semantic HTML, plain CSS, and minimal vanilla JavaScript with zero external runtime dependencies.

Live URL (once GitHub Pages is enabled): `https://ben-kodbiz.github.io/mybio/`

## Local Preview

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.
